### 🚀 Опис проекту
Кросплатформний застосунок на базі **.NET MAUI** для комплексного аналізу, пошуку, фільтрації, XSLT-трансформації та хмарного експорту XML-даних про програмне забезпечення факультету.

### 📋 Структура XML-даних (Варіант 9)
Вхідний XML-документ (`Data/FacultySoftware.xml`) відповідає всім вимогам методичних вказівок:
* **2-рівнева структура:** `FacultySoftwareNetwork` $\rightarrow$ `Department` (кафедри) $\rightarrow$ `Software` (програмні засоби) $\rightarrow$ деталі.
* **Різна кількість атрибутів у головних вузлах:** вузли `<Software>` містять від 3 до 6 атрибутів (`Name`, `Version`, `Category`, `License`, `Author`, `Arch`, `InstallationType`).
* **Дочірні елементи:** `<Description>`, `<DistributionLocation>`, `<Requirements>`, `<MaintainedBy>`.

### 🏗️ Реалізовані патерни проєктування (Design Patterns)

#### 1. Патерн «Стратегія» (Strategy Pattern)
Забезпечує взаємозамінний пошук та розбір XML трьома принципово різними способами:
* **`SaxXmlSearchStrategy` (SAX API)** — потоковий однопрохідний аналіз на базі `XmlReader` без завантаження дерева в оперативну пам'ять (мінімальні витрати ресурсів).
* **`DomXmlSearchStrategy` (DOM API)** — повна об'єктна модель документа в пам'яті на базі `XmlDocument` із динамічною генерацією виразів мови **XPath**.
* **`LinqXmlSearchStrategy` (LINQ to XML)** — декларативні запити за допомогою класів `XDocument` та `XElement` з використанням лямбда-фільтрів.
* **`XmlSearchContext`** — контекст для перемикання активної стратегії в реальному часі через інтерфейс.

#### 2. Патерн «Фабричний метод» (Factory Method Pattern)
Використовується для експорту відфільтрованих фрагментів даних на **Google Drive** у різних форматах:
* **Базовий творець (`GoogleDriveExportService`)**: містить загальний алгоритм роботи з відкритим файлом у пам'яті (MemoryStream), виклику фабричного методу та завантаження на Google Drive.
* **Фабричний метод:** `protected abstract IDataExporter CreateExporter();`
* **Конкретні творці:**
  * `GoogleDriveXmlExportService` $\rightarrow$ створює `XmlDataExporter` (збереження у формат `.xml`);
  * `GoogleDriveHtmlExportService` $\rightarrow$ створює `HtmlDataExporter` (збереження у формат `.html`).

#### 3. Патерн «Одинак» (Singleton Pattern)
Централізована потокобезпечна система протоколювання подій **`AppLogger`**:
* Зберігає журнал подій у локальний файл на диску (`event_log.txt`).
* Підтримує **3 обов'язкові рівні важливості подій**:
  1. `Фільтрація` (фіксує використану стратегію, параметри пошуку та кількість знайдених записів);
  2. `Трансформація` (фіксує виклики XSLT та розмір HTML-звіту);
  3. `Збереження` (фіксує експорт файлів у Google Drive з ID та форматом).

### 🌐 XSLT-трансформація
* Файл стилів [`Data/SoftwareReport.xsl`](Data/SoftwareReport.xsl) перетворює вихідні або відфільтровані XML-дані у гарний, адаптивний HTML-звіт з табличною структурою, кольоровими бейджами та групуванням по кафедрах.
* Реалізовано за допомогою системного класу `XslCompiledTransform`.
* У програмі доступний попередній перегляд HTML прямо у вікні через `WebView` та відкриття у зовнішньому веб-браузері.

### 🖥️ Можливості графічного інтерфейсу (.NET MAUI)
* **Динамічна «підгрузка даних»:** при завантаженні файлу випадаючі списки (Picker) автоматично наповнюються актуальними значеннями кафедр, категорій, авторів та ліцензій.
* **Кнопка Clear:** очищує всі встановлені фільтри, ключові слова та скидає відображення.
* **Підтвердження виходу:** діалогове вікно запитує *«Чи дійсно ви хочете завершити роботу з програмою?»* («Так» / «Ні»).
* **Захист від витоку ключів:** файл `client_secrets.json` включено до `.gitignore` (додано зразок `client_secrets.json.example`).

### 🚀 Запуск проєкту
1. Відкрийте папку проекту у Visual Studio 2022 або VS Code.
2. Для роботи з Google Drive скопіюйте файл `client_secrets.json.example` як `client_secrets.json` та вкажіть ваші OAuth-ключі.
3. Запустіть проект:
   ```bash
   dotnet build -f net8.0-windows10.0.19041.0
   dotnet run -f net8.0-windows10.0.19041.0
   ```
